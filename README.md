# Analysis-of-customer-behavior-and-operational-activities-Uber
### 📌 Context:

Uber—a leading ride-hailing app—seeks to optimize operational efficiency and user experience management. Management has observed frequent fluctuations in trip cancellation rates and customer waiting times (VTAT/CTAT), alongside untapped revenue potential across different vehicle segments and time slots.

> **Note:** This project utilizes an AI-generated synthetic dataset created to simulate realistic Uber ride-sharing operations for 2024.

### 🎯 Core Objective:
Leverage the Uber trip operations dataset using Python, SQL, and Power BI to analyze operations, revenue, cancellation drivers, and customer segmentation, thereby formulating strategic recommendations to improve trip completion rates and optimize revenue.
